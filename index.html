Como funciona o projeto

As câmaras captam imagem e enviam o sinal para o computador central, que permite visualizar e gerir os diferentes pontos de vigilância através de uma aplicação compatível com os equipamentos instalados.

Componentes principais

  • Câmaras IP ou câmaras compatíveis
  • Computador para gestão e visualização
  • Rede local, router ou switch
  • Software de monitorização e armazenamento
